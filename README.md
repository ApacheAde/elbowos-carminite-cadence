# Carminite Cadence

Full-colour Python 3 crimson rhythm-tap arcade for ElbowOS.

Lanterns fall in four wine-dark lanes. Tap as each diamond crosses the gold line. Perfect hits build a chain. A miss or a whiff snaps it.

A / S / D / F (or arrows) tap the lanes. R restarts.

## Play

```
pip install -r requirements.txt
python3 carminite_cadence.py --play
```

## Record a 9:16 reel

```
python3 carminite_cadence.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
